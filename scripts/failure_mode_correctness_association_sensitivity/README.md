# Failure Mode–Correctness Sensitivity Analyses

`build_sensitivity_analysis.py` produces:

- question-cluster bootstrap checks for unadjusted RD, RR, and OR;
- pooled GLMM–GEE direction and FDR-significance comparisons.

Outputs are written to `Preprint/analysis/failure_mode_correctness_association/sensitivity_analysis`.

## Run

From the code repository root:

```bash
bash scripts/failure_mode_correctness_association_sensitivity/run_analysis.sh
```
